Install on iPhone

Safari의 공유 메뉴에서 홈 화면에 추가할 수 있습니다.

  1. Safari 하단의 공유 버튼을 누릅니다.
  2. 홈 화면에 추가를 선택합니다.
  3. 오른쪽 위의 추가를 누릅니다.

현재 연결은 iPhone에서 안전한 HTTPS로 인정되지 않아 오프라인 기능이 비활성화됩니다. PC에서 npm run setup:https를 실행하고 생성된 루트 인증서를 iPhone에서 신뢰해 주세요.
